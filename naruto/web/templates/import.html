Upload a Telegram Desktop export

  1. In Telegram Desktop, open the group → ⋮ → Export chat history.
  2. Choose Machine-readable JSON. Untick photos, videos, voice messages, stickers and files: text only keeps the file small (media is stored as markers like [photo]).
  3. Upload the result.json it creates. You'll see a preview before anything is imported.

Only messages from before the bot's first recorded message are imported, and only those from the last {{ retention_days if retention_days else "∞" }} days (Settings → Retention). Importing the same group again replaces the previous import. The uploaded file is deleted once the import finishes.
