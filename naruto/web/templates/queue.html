Model queue

Every request to the model server goes through this queue. Replies to people start before waiting background work (digest upkeep, history summaries, import memory); within each, first come, first served.

Limits

Set parallel requests to the number of slots your model server has; this page doesn't create them. Background work may use at most parallel − kept slots (kept is capped at parallel − 1, so a one-slot server still runs it). Lowering a limit lets running requests finish. These are also on the Settings page, with their history.
